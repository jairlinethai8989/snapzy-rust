# SnapZy 0.15.0-alpha.16 trial

This trial adds arrowhead presets, speech bubble frame presets, and Ctrl+Z history handling.

- Arrow: end head or both ends; curved arrows keep both heads attached to the endpoints.
- Speech bubble: rounded, square, or oval frame; the tail remains draggable.
- History: Ctrl+Z undo, Ctrl+Shift+Z or Ctrl+Y redo; text inputs retain their own editing shortcuts.
- Project schema 7 stores the new object properties and reads schema 1–6.

The public README link remains on the previously published installer until this trial is manually tested.
