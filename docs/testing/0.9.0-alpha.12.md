# Alpha 12: Shape Resize And Object Opacity

Local portable test candidate, Rust only. No commit/push or public release.
Retain Alpha 11 and Alpha 10 as separate candidates.

## Changes

- Eight handles immediately after drawing outline/filled rectangles and ellipses.
  Keep drawing mode; Select can edit older shapes. Corners resize both axes;
  edge handles resize one axis. Opposite edges stay fixed, minimum size is 1 px.
- Resize retains object identity, style, pattern, opacity and layer order.
  Release commits one Undo step; Esc/capture loss/tool change cancel a drag.
- Object opacity 0-100%, excluding blur and the captured background. Ordinary
  defaults 100%, Highlighter 40%; inserted images start at 100%.
- Text/fill, bubbles, arrows and numbered circles fade as complete objects.
  Source pixels/alpha remain unchanged. Invisible objects remain editable.
- EN/TH Help/tooltips; opacity and text background/border controls do not overlap.

## Tester Checklist

1. Draw each outline/filled shape and drag corners and edge handles immediately.
2. Draw a second shape away from handles, then Select and resize the older shape.
3. Resize, Undo/Redo, cancel with Esc, switch tools and release outside the image.
4. Change shape opacity to 50%, 0%, then select the invisible shape and restore it.
5. Try opacity on pen, curved arrow, text with background, bubble, number and image.
6. Confirm normal 100% and highlight 40% defaults remain independent.
7. Copy/export PNG; compare with editor at 100% zoom. Try text controls in EN/TH.
8. Recheck Lark long capture and Esc/Stop, which this increment does not change.
