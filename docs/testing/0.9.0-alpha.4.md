# SnapZy Rust Preview 0.9.0-alpha.4 Tester Report

## Candidate

- Windows x64 portable ZIP: `SnapZy-Rust-0.9.0-alpha.4-win-x64.zip`.
- Extract into a new folder and run `SnapZy-Rust.exe`.
- Close any already-running Rust Preview first; versions share a
  single-instance identity.
- Local test build only. It has not been pushed to Git.

## Fix

- Repeated clicks no longer start a second detection while the current pane
  detection is in progress. This prevents overlapping UI Automation requests
  from invalidating the active result and repeatedly hiding/showing the overlay.
- Clicking another point remains available after a completed no-match result.

## Automated Verification

- `cargo test --locked`: 117 passed.
- Release x64 build passed. Native scrolling smoke did not reach detection:
  the harness failed to position the test cursor. That run did not verify the
  selection-click flow, duplicate input or Escape during detection.
- Subsequent tester feedback reported selection clicks were unusable. Alpha 5
  addresses click-release handling and a missing overall provider deadline.
- The native fixture is not Lark. The two Lark sheets and Excel still need
  hands-on testing; automatic scrolling remains unverified on those targets.

## ภาษาไทย

1. ปิด Rust Preview รุ่นเดิมจาก System Tray ก่อน แล้วแตก ZIP Alpha 4 ไปยัง
   โฟลเดอร์ใหม่ เปิด `SnapZy-Rust.exe` และตรวจเวอร์ชัน 0.9.0-alpha.4
2. เลือก **Scrolling** แล้วคลิกหนึ่งครั้งในตาราง Lark ที่เคยมีปัญหา ระหว่างขึ้น
   สถานะกำลังตรวจจับ ให้ลองคลิกซ้ำเร็ว ๆ หน้าต่างไม่ควรกระพริบหรือเริ่มตรวจซ้ำ
3. กรอบตรวจพบควรแสดงเพียงครั้งเดียว จากนั้นกดยืนยันและทดสอบจับภาพยาว
   ตรวจแถวตรึง รอยต่อภาพ และความต่อเนื่องของแถว
4. กด Esc ระหว่างตรวจจับและหลังแสดงกรอบ ต้องยกเลิกได้โดยไม่ต้องกดปุ่มบนจอ
5. ถ้าขึ้นว่าไม่พบพื้นที่เลื่อน ให้คลิกจุดอื่นเพื่อทดลองใหม่ได้
6. ทดสอบทั้งสองแผ่นงาน Lark ที่เคยมีปัญหาและ Excel ทั้ง Automatic และ Manual

## English Quick Checklist

- Repeated clicks during detection do not restart detection or flash the overlay.
- A completed no-match result can be retried by clicking another point.
- Escape cancels both while detection is pending and after a candidate appears.
- Confirmed pane bounds match the scrollable viewport; inspect frozen rows,
  seams, pause/resume, Stop, Cancel and exported PNG dimensions.

Synthetic native tests do not establish Lark/Excel compatibility. Please report
the manual results before approving a Git push.
