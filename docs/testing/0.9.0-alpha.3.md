# SnapZy Rust Preview 0.9.0-alpha.3 Tester Report

## Candidate

- Windows x64 portable ZIP: `SnapZy-Rust-0.9.0-alpha.3-win-x64.zip`.
- Extract into a new folder and run `SnapZy-Rust.exe`.
- Close any already-running Rust Preview first; versions share a
  single-instance identity.
- Local test build only. It has not been pushed to Git.

## Fixes

- Cache the native window chain under the clicked point before the detector
  restores its overlay. The native scrollbar fallback no longer hit-tests the
  SnapZy overlay instead of the target application.
- Keep Escape registered on the scrolling overlay during provider work, and
  restore keyboard focus when the overlay is shown again.
- Stop UI Automation ancestor traversal cleanly if a provider rejects a parent
  request, preserving any valid scroll pane already found.

## Automated Verification

- `cargo test --locked`: 117 passed.
- Release x64 build succeeded.
- Native `ScrollChecks` passed with a 350 ms artificial UIA handoff delay. This
  forces the overlay to reappear before native fallback, reproducing the
  detection race.
- The same smoke run verified Escape cancellation during provider work and
  after candidate preview, plus manual wheel handoff, exact stitching,
  target-movement pause, Stop/Cancel and clipboard pixel parity.
- The native fixture is not Lark. The two Lark sheets and Excel still need
  hands-on testing; automatic scrolling remains unverified on those targets.

## ภาษาไทย

1. ปิด Rust Preview รุ่นเดิมจาก System Tray ก่อน แล้วแตก ZIP Alpha 3 ไปยัง
   โฟลเดอร์ใหม่ เปิด `SnapZy-Rust.exe` และตรวจเวอร์ชัน 0.9.0-alpha.3
2. เลือก **Scrolling** แล้วคลิกหนึ่งครั้งภายในพื้นที่ตาราง Lark ที่ต้องการ
   ตรวจจับ กรอบที่พบต้องครอบเฉพาะพื้นที่เลื่อน ไม่ใช่ overlay ของ SnapZy
3. กด Esc ระหว่างขึ้นสถานะกำลังตรวจจับ และลองอีกครั้งหลังกรอบแสดง ต้องยกเลิก
   ได้โดยไม่ต้องคลิกปุ่มบนหน้าจอ และต้องไม่เริ่มจับภาพ
4. ลองคลิกพื้นที่เดิมใหม่ ตรวจกรอบ แล้วกดยืนยัน เริ่มทั้ง Automatic และ
   Manual แยกกัน ตรวจแถวตรึง รอยต่อภาพ การพัก/ทำต่อ Stop, Cancel และ PNG
5. ทดสอบ Lark ทั้งสองแผ่นงานที่เคยมีปัญหาและ Excel หากตรวจไม่พบหรือกรอบผิด
   ให้คลิกจุดอื่นเพื่อลองใหม่ แล้วแจ้งข้อความหรือแนบภาพหน้าจอ

## English Quick Checklist

- Click once inside each target sheet; confirm the highlighted bounds match the
  scrollable viewport.
- Escape cancels both while detection is pending and after a candidate appears.
- Retry by clicking another point. Confirmation starts capture only once.
- Test both Lark sheets and Excel in Automatic and Manual modes; inspect frozen
  rows/columns, seams, pause/resume, Stop, Cancel and PNG dimensions.

Synthetic native tests do not establish Lark/Excel compatibility. Please report
the manual results before approving a Git push.
