# SnapZy Rust Preview 0.3.0-alpha.1 Verification

Date: 2026-10-09, Asia/Bangkok. Local portable Windows x64 tester build only.
No push, tag or GitHub release. The .NET SnapZy and Neo Snap repos are unchanged.
Approved scope: text, automatic step numbers and reversible region blur.

## Changes

- Native multiline Thai/English text entry, editing and movement. Initial font
  size 24 source pixels, adjustable from 8 to 128; current annotation color.
- Numbered circles, initial diameter 36 source pixels, adjustable from 20 to 120.
  New numbers follow the highest existing document number, including cropped
  objects. Deleting a middle number does not renumber other objects.
- Droplet blur tool, Gaussian strength 8 source pixels by default, range 2-30.
  Stored rectangles are editable; movement, deletion and Undo restore source
  pixels. Blur includes earlier annotations beneath it in document order.
- Tool-specific settings, translated tooltips and Help. Existing red color,
  5 px strokes, buffered painting and antialiased live shape drafts are retained.
- Background composition with generation/owner checks. Copy and PNG export are
  disabled until the latest revision is ready, preventing stale exports.

## Limits

Captured source pixel storage across windows is limited to 32 MiB, reserving
capacity for composition/display/filter buffers under the conservative pixel
budget; this is not a bound on total process memory. Text masks retained across
objects/history are capped at 1 MiB per document. Rejected edits report an error
without discarding the document. History retains up to 64 steps.

Blur is visual obfuscation, not secure redaction; the original image remains in
memory. Do not use it as a guarantee that sensitive text cannot be inferred.
This preview does not add speech bubbles, shadows, layers, multiple-image merging,
project saving, OCR, scrolling capture, recording or an installer.

## Tester Checklist

1. Exit the previous Rust Preview using its tray menu, extract the ZIP and run
   `SnapZy-Rust.exe`. No installer or .NET runtime is required.
2. Capture an area/window and compare perceived launch/capture speed with alpha.2.
   Hover, resize, move objects and draw diagonal strokes; check for flicker and
   abrupt changes in edge smoothness after releasing the mouse.
3. Select T, click an image, type Thai and English on multiple lines, then Apply.
   Test Cancel, color, font size, selection/movement and editing the same text
   using T or Select double-click. Test actual Thai IME and punctuation.
4. Place numbers 1, 2, 3; delete 3 and place again (expect 3). Delete 2 and place
   again (expect 4, no automatic renumbering). Check diameter, crop and Undo/Redo.
5. Drag a blur region, change its strength, move/delete it and use Undo/Redo.
   Confirm pixels outside its region are unchanged. On a large image, confirm
   the window responds while processing and Copy/Save wait for the latest result.
6. Copy annotations and paste into a chat app; save PNG and compare dimensions,
   text, numbers and blur with the preview. Check separate editor windows.
7. Switch EN/TH and inspect Help/tooltips. Test 125%, 150% and 200% display scaling,
   including moving between differently scaled monitors, before release approval.

Report any failure with the tool, image dimensions, display scaling, steps and
whether it occurred during dragging, after release, on Copy or in the saved PNG.
