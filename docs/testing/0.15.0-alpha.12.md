# SnapZy 0.15.0-alpha.12: Close choices and System Tray

- Editor window X asks Close / Close all tabs / Cancel.
- Close affects the active tab. Close all tabs affects the current editor window.
- Close all asks Save all / Discard all / Cancel once for the entire set of unsaved tabs. Save all may still require filenames for projects without a saved path.
- Cancel preserves every tab. A preview error does not block the discard path.
- The Tauri application creates its own tray icon during startup, before the capture engine is needed.
- Closing the capture launcher hides it to the tray. Clicking the tray icon restores and focuses the launcher.
- The tray menu offers Open SnapZy, Minimize to tray, and Exit. Exit retains the unsaved-project confirmation workflow.

## Validation

Run `npm test` and `node tests/close-all-ui-smoke.mjs` from `experiments/tauri`.
Run `cargo test --manifest-path experiments/tauri/src-tauri/Cargo.toml --locked` from the repository root.

On Windows, launch the packaged Alpha 12 application, verify its tray icon, close the launcher with X, then restore it from the tray. Exit from the tray and verify process shutdown. With two test tabs, use the Editor X, cancel, then select Close all and Discard all once.
