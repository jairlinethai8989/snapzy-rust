# SnapZy Rust 0.13.0-alpha.1 Test Notes

## Scope

This candidate completes ordinary one-way Neo Snap `.neosnap` version 1
annotation import by adding editable text and speech bubbles. It retains source
text and line breaks, anchor, font size, color, opacity, shadow, text outline,
image ownership and layer order. Bubbles also retain body width/minimum height,
fill, independent border color and width, and the movable tail. Small differences
in glyph antialiasing, wrapping and glyph height are expected between the .NET
browser canvas and native Windows text rendering.

Imported work opens as an unsaved Rust document and can only be saved as a new
`.snapzy` schema 4 project. SnapZy Rust never overwrites the source `.neosnap`.
If any object or active value cannot be preserved, the complete import stops;
no object is dropped, flattened, reordered or clamped.

## Manual Test Checklist

1. Exit every older SnapZy Rust process, including its tray icon.
2. Extract `SnapZy-Rust-0.13.0-alpha.1-win-x64.zip` to a new folder and run
   `SnapZy-Rust.exe` from that folder.
3. In Neo Snap .NET, save a `.neosnap` containing Thai/English multiline text
   and speech bubbles with different text, fill, border, outline and shadow colors.
4. Open the file in SnapZy Rust. Compare positions, line breaks, body dimensions,
   opacity, effects, tail positions and layer order. Minor wrapping differences
   are acceptable; missing text or objects are not.
5. Edit imported text, including a large font up to 256 px. Move and resize it,
   then verify Undo/Redo.
6. Select an imported bubble. Drag a side to change wrapping without changing
   font size; drag a corner to scale the font, frame and tail. Move the tail.
7. Change text color, fill color, the separate border color/width, opacity,
   shadow and text outline. Verify each change is independent and undoable.
8. Repeat with text/bubbles owned by a resized imported image. Their visible
   position, scale, clipping and layer order must remain stable.
9. Use Copy Image and Save PNG. Both must match the editor preview.
10. Save as `.snapzy`, close, reopen and continue editing. Confirm the original
    `.neosnap` is unchanged.
11. Open older schema 1, 2 and 3 `.snapzy` work and confirm native text/bubbles
    retain their earlier appearance.
12. Retest combine images, OCR, scrolling capture with Esc/Stop, and video
    recording/preview.

## Safety And Status

Blur remains visual obfuscation, not secure redaction. Editable projects retain
source pixels beneath blur; share an exported PNG when hidden source data must
not be included. This candidate is portable, does not install or update the .NET
application, and has not been committed, pushed or published.
