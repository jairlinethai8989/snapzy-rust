# SnapZy Rust Preview 0.6.0-alpha.1

Local portable tester candidate, 2026-10-10 (approved 2026-10-09). Automatic scrolling increment only;
no installer, public release, Git commit/push or .NET changes.

## Scope

Automatic / Manual launcher choice (Automatic default; saved Rust-only setting).
One bounded, target-specific WM_MOUSEWHEEL per validated step; 600 ms render delay
then existing stable-frame gate. No cursor repositioning/global input fallback.
Pause/Resume, Stop with accepted pixels, Cancel, latched focus/occlusion/input
safety pauses. Three quiet no-motion attempts end with an explicit notice that
the document may not have ended. Existing conservative joins and memory limits
remain unchanged. A timed-out message cannot revoke input already delivered to
the target; the worker never deliberately sends a further command after cancellation.

  `manual_dangling_ptr`). No new allowance for the automatic-scrolling code.

The untitled covering fixture uses native non-activating show; ordinary Form.Show
on this host activated it and could not independently test occlusion.
Failed/preliminary artifacts are retained, not counted as passing final runs.

## Performance Comparison

Final same-machine comparison, three alternating samples per build:
`artifacts/comparison-0686c06fbfd940c4877702cd3a9d6db9/comparison.json`.
Baseline is the preserved, accepted alpha5 EXE (E5B120...); candidate is final
alpha6 (0CC7D9...). All six ordinary-capture smoke runs passed. No native UI test
or build was running concurrently. This is Rust-to-Rust, not a .NET comparison.

| Metric (ms, median / slowest) | alpha5 | alpha6 |
| --- | --- | --- |
| Launcher window detection | 261.450 / 387.440 | 296.930 / 328.150 |
| In-app launcher ready | 45.046 / 53.459 | 45.281 / 49.756 |
| Selection first paint | 169.499 / 202.870 | 185.579 / 187.236 |
| Preview first paint after selection | 119.513 / 135.522 | 121.731 / 139.680 |

Peak working-set median: alpha5 106,553,344 bytes; alpha6 106,307,584 bytes.
Selection median was 16.080 ms higher and preview median 2.218 ms higher in this
small sample. Do not claim a speedup or zero overhead; three samples cannot
establish a statistically reliable performance regression/non-regression.
The previous 3.26-second alpha5 launch outlier was not reproduced here and is
still unexplained. Window detection, in-app ready and completed paint are
different measurements; none alone proves end-to-end startup on other PCs.
