# SnapZy Rust Preview 0.9.0-alpha.11

Date: 2026-10-11 (Asia/Bangkok). Local test candidate only.
No commit, Git push, public release, installer or .NET changes. Alpha 10 retained.

## Scope

- Immediately bend/reset the selected newly drawn Line/Arrow while keeping its
  drawing mode. Drag elsewhere to draw another object; Select edits older objects.
- Two grouped shape buttons: Outline shapes and Filled shapes. Whole-button
  click opens rectangle/ellipse choices; checked menus, matching icons and EN/TH
  descriptions remember each group's last variant per editor independently.
- Menu cancellation does not change the tool, document, selection or preferences.
- Shared painting/input handle eligibility, including crop and unfinished gestures.

## Tester Steps

1. Close the older Rust Preview and open this separate portable candidate.
2. Draw a line; immediately drag its circular midpoint. The endpoints stay fixed.
   Double-click the midpoint to straighten; test Undo/Redo and Esc while bending.
3. Draw another line elsewhere without pressing the Line button again. Only the
   currently selected object's handle appears. Select still edits older objects.
4. Repeat with Arrow; verify its head follows the curve. Try solid/dashed/dotted.
5. Open Outline shapes and choose Ellipse; open Filled shapes and choose Rectangle.
   Reopen each menu: the correct independent choice is checked and the icon matches.
6. Cancel either popup with Esc. Continue drawing with the previous tool; the image
   and Undo history should be unchanged. Switch EN/TH and inspect Help/tooltips.
7. Verify pen/highlighter, text/callout, blur, layers, crop, OCR, PNG/clipboard and
   scrolling capture Stop/Esc still work. Test Lark on a real sheet independently.

## Limitations

Further native desktop checks require a newly agreed input-free interval. Do not infer
live Lark coverage or mixed-DPI/physical-input latency from unit or fixture tests.
Circle is an ellipse drawn with equal dimensions; no Shift-constrain shortcut.
