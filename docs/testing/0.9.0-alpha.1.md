# SnapZy Rust Preview 0.9.0-alpha.1 Tester Report

## Candidate

- Windows x64 portable ZIP: `SnapZy-Rust-0.9.0-alpha.1-win-x64.zip`
- Install: extract the ZIP to a writable folder and run `SnapZy-Rust.exe`.
- No Git push has been made. This is a local test candidate.
- OCR language data is not bundled. The app asks before downloading it.

## Changes

- Adds local Tesseract OCR for Thai + English (default) or English.
- Reads the current composed image, including added images and annotations,
  at its original pixel size; editor controls and selection handles are excluded.
- Results are editable and copied as Unicode text only when Copy is selected.
- First-use language downloads require consent, use HTTPS and SHA-256 checks,
  and remain in the SnapZy Rust Preview data directory. After setup, OCR works
  offline. Images are processed locally and are not uploaded.
- OCR runtime libraries load on demand; capture and image editing remain usable
  if OCR setup is declined or unavailable.

## Automated Verification

- `cargo test --locked --bin snapzy-rust`: 110 passed, including actual OCR of
  English, Thai, mixed-language and blank fixture images with local models.
- Opt-in live HTTPS download test: English model downloaded and verified against
  its pinned size and SHA-256.
- Release x64 build completed; the app executable is approximately 1.6 MB.
- Native UI regression harness exercises existing capture, editor, scrolling,
  layers and multi-image workflows. OCR window controls, Thai + English default,
  no-read-on-open and close lifecycle are smoke-tested. Consent/refusal, actual
  read/copy and offline behavior still need tester checks below.
- Startup and capture latency have not been benchmarked against alpha8 in this
  OCR milestone.

## ภาษาไทย

### วิธีเริ่มทดสอบ

1. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่เขียนไฟล์ได้ แล้วเปิด `SnapZy-Rust.exe`
2. จับภาพหรือเปิดภาพ จากนั้นเปิดหน้าแก้ไขและเลือกไอคอน OCR
3. ตรวจว่าเมื่อเปิดหน้าต่าง OCR เฉย ๆ ยังไม่เริ่มอ่านและไม่ดาวน์โหลดโมเดล
4. เลือก `Thai + English` หรือ `English` แล้วกด `Read text`
5. เมื่อถามดาวน์โหลดโมเดล ให้ตรวจข้อความแจ้งขนาด/แหล่งที่มา แล้วเลือกยอมรับ
   หรือปฏิเสธตามรายการใน checklist
6. แก้ไขข้อความผลลัพธ์ แล้วกด Copy และวางใน Notepad หรือช่องข้อความที่รองรับ
7. ปิดแล้วเปิด OCR อีกครั้งโดยปิดอินเทอร์เน็ต เพื่อทดสอบโมเดลที่ติดตั้งแล้ว

### สิ่งที่ควรสังเกต

- ค่าเริ่มต้นเป็น Thai + English; ตัวเลือก English ควรอ่านภาษาอังกฤษได้
- การปฏิเสธหรือดาวน์โหลดล้มเหลวไม่ควรปิดกั้นการจับภาพ/แก้ไขภาพ
- ข้อความที่คัดลอกต้องเป็น Unicode รวมถึงภาษาไทยและการขึ้นบรรทัดใหม่
- ภาพไม่มีข้อความควรแจ้งว่าไม่พบข้อความ โดยไม่ทำให้โปรแกรมค้าง
- หากปิดหน้าต่าง OCR หรือหน้าแก้ไขระหว่างกำลังอ่าน ต้องไม่แสดงผลเก่าทับหน้าต่างอื่น
- ภาพขนาดใหญ่เกินข้อจำกัดควรแจ้งให้ crop ภาพก่อน ไม่ควรทำให้โปรแกรมล้ม

รายงานผลพร้อมภาพหน้าจอหรือไฟล์ log หากพบปัญหา ก่อนอนุมัติ push ขึ้น Git

## English Quick Checklist

- Opening OCR alone does not start recognition or download models.
- Thai + English is selected by default; English-only is available.
- Consent is shown before first download; refusal leaves capture/editor usable.
- Read text succeeds for Thai, English and mixed-content screenshots.
- Result text is editable and Unicode Copy preserves Thai characters/newlines.
- Blank image reports no text; oversized image gives an actionable crop message.
- Installed models work offline; a failed/interrupted download can be retried.
- Closing OCR/editor during work does not deliver stale output to another window.
