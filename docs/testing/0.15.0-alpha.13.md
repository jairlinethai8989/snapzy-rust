# SnapZy 0.15.0-alpha.13: Workspace navigation after zoom

The fixed viewport previously clipped zoomed images while ordinary dragging invoked the drawing tool and ordinary wheel scrolling had no handler. Panning was only available through Space or the middle button.

- A hand toggle beside zoom enables left-button panning, including while Text/Callout was selected. Choosing a drawing tool exits hand mode.
- Ordinary wheel scrolls vertically, Shift + wheel horizontally, and trackpad delta X/Y both work. Ctrl + wheel still zooms around the pointer.
- Space + drag and middle-button drag remain available. Hand cursors distinguish ready/dragging states.
- Pan bounds keep at least a small part of the image reachable, including after window resize. Fit restores the full image.
- View navigation leaves document objects and undo history unchanged and retains the per-tab viewport.

Run `npm test`, `node tests/editor-pan-ui-smoke.mjs`, and `node tests/editor-ui-smoke.mjs` from `experiments/tauri` with `npm run dev` running.

Manual installer check: open a tall image or combined document, zoom beyond Fit, toggle the hand button and drag in each direction. Verify wheel/Shift-wheel, Space/middle drag, drawing after selecting a tool, switching tabs, and Fit. Test window resize and Thai/English tooltips.

## Installer lock correction

The process guard omitted `snapzy-engine.exe`. An orphan capture engine could therefore lock `engine/snapzy-engine.exe` after the launcher had exited, while setup incorrectly allowed extraction to start. The guard now checks the engine as well and explains how to close it before Retry. Setup does not terminate processes automatically.

`node tests/installer-process-smoke.mjs` launches a real bundled editor-service process, verifies setup blocks with exit code 20 while only that engine runs, closes the test engine, and verifies the guard returns 0. Run this test with SnapZy closed.

The repaired installer has suffix `-installer-fix.exe`; its application version remains `0.15.0-alpha.13` because only the setup guard and setup message changed.
