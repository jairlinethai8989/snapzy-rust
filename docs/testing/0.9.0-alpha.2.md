# SnapZy Rust Preview 0.9.0-alpha.2 Tester Report

## Candidate

- Windows x64 portable ZIP: `SnapZy-Rust-0.9.0-alpha.2-win-x64.zip`
- Extract to a new writable folder and run `SnapZy-Rust.exe`.
- Close any already-running Rust Preview before testing; versions share the
  same single-instance identity.
- This is a local test build. It has not been pushed to Git.

## Changes

- Scrolling capture now starts by clicking inside the pane to capture.
- SnapZy detects a vertically scrollable viewport and highlights it for review.
- **Start long capture** confirms the candidate and starts the existing
  Automatic or Manual workflow. Detection itself does not scroll the target.
- Click a different point to retry detection. Press Escape to cancel. There is
  no drag-to-select fallback for scrolling mode.
- Detection uses Windows UI Automation and a limited native scrollbar fallback.
  App compatibility varies, so this release does not claim that every sheet or
  application exposes a detectable pane.

## Automated Verification

- `cargo test --locked`: 117 passed.
- Release x64 build succeeded.
- Native `ScrollChecks` passed for click detection, preview and confirmation,
  manual wheel handoff, target movement pause, Stop/Cancel, exact stitching and
  clipboard pixel parity.
- The automatic smoke fixture sent wheel input and verified the initial pause
  and resume steps, but did not complete its end-of-content dialog assertion:
  the safety guard detected another topmost window over the test pane. Treat
  Automatic as requiring hands-on validation in this candidate.
- The smoke fixture uses a native scrollbar. Actual Lark Sheets and Excel have
  not been tested by this harness and require your manual validation.

   และข้อความที่แสดง ไม่ต้องพยายามจับภาพทั้งหน้าต่างแทน

## English Quick Checklist

- Scrolling mode asks for one click inside the intended content pane.
- The detected viewport is highlighted and can be reviewed before confirmation.
- No source scrolling occurs before **Start long capture** is confirmed.
- Clicking elsewhere retries; Escape cancels; no drag-selection fallback exists.
- Try both previously problematic Lark sheets and an Excel sheet in Automatic
  and Manual modes. Check frozen rows/columns, seams, Stop, Cancel and PNG size.

Automated native tests are not evidence of Lark/Excel compatibility. Please
report the result before approving a Git push.
