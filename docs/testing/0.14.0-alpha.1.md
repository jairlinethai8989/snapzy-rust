# SnapZy Rust 0.14.0-alpha.1 Test Notes

## Scope

This local candidate replaces the launcher and editor chrome with a compact,
adaptive native Windows interface. It keeps the accepted capture, scrolling,
editor, project, OCR, video and `.neosnap` import behavior from 0.13.0-alpha.1.
No .NET source or accepted 0.13 package is changed.

The launcher targets 360 x 140 logical pixels. Area, Window, Scrolling and Video
remain direct actions. Window has a separate Desktop menu; Open Image and EN/TH
remain direct; Hotkeys, About, Hide and Exit are under More. The editor keeps
Copy and Save PNG visible and moves secondary commands into short More and Layer
menus when the window is narrow.

รุ่นทดสอบนี้ปรับเฉพาะโครงหน้าหลักและหน้าแก้ไขให้เป็น Native Windows ที่กะทัดรัด

ไม่ถูกแก้ไข

## Manual Test Checklist

1. Exit every older SnapZy Rust process, including the tray icon.
2. Extract `SnapZy-Rust-0.14.0-alpha.1-win-x64.zip` into a new folder and run
   `SnapZy-Rust.exe` from that folder.
3. Confirm the launcher is compact and does not clip at Windows scale 100%,
   125%, 150% and 200% where available.
4. Test Area, Window main action, Window > Desktop, Scrolling and Video. Confirm
   the split arrow opens the menu without starting Window capture.
5. Test Open Image, EN/TH and More > Hotkeys/About/Hide/Exit. Reopen from the
   tray after Hide.
6. Hover every launcher button. Confirm the localized tooltip appears after a
   short delay and the window does not lose focus.
7. Open the editor in English and Thai. Check every icon is recognizable and
   has a tooltip. Verify hover, selected, disabled, focus and Delete states.
8. Resize the editor around its 780 px minimum and above 1000 px. Copy and Save
   PNG must stay visible; secondary commands must move between direct buttons
   and More without overlap.
9. Test the two grouped shape menus and the Layer menu. Confirm their short EN/TH
   labels route to the correct command.
10. Retest one complete workflow each for capture, automatic scrolling with
    Esc/Stop, image editing and Undo/Redo, `.snapzy` open/save, `.neosnap`
    import, OCR and video record/preview/save.
11. Confirm clipboard pixels and saved PNG match the editor preview.
