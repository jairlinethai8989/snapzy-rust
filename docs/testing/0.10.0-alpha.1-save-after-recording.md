Existing packages are preserved. No commit, push, installer or .NET edits.

## Changes

Selecting the monitor/window now starts preparation and countdown directly.
Stop/Esc finalizes the clip before showing Save video. Cancel keeps the recorded
clip under the instance data directory's Recordings/Pending folder and shows
its location. It also cancels pending app exit.

Saving on the same volume moves the existing file without needing space for a
second full-size clip. Saving across volumes uses bounded streaming in a
background thread and publishes without overwriting a destination. Save failure
keeps the original clip. Explicit Exit waits until saving completes.

2. Video > Record screen or Record window, then select the source.
3. Verify 3-2-1 begins without a Save chooser. Record motion for 15 seconds.
