# SnapZy Rust Preview 0.9.0-alpha.10

รุ่นทดลองแยกจาก SnapZy/Neo Snap เดิม ไม่ต้องติดตั้ง .NET

## รูปทรง รูปแบบเส้น และการดัดโค้ง (ใหม่)

1. ปิดรุ่นเดิมจาก Tray แตก Alpha 10 ลงโฟลเดอร์ใหม่ เปิด EXE ตรวจ 0.9.0-alpha.10
2. วาดกรอบสี่เหลี่ยม/วงรี และสี่เหลี่ยม/วงรีทึบ ลากย้อนทิศด้วย รูปทึบต้องปิดช่อง
   ขนาดเส้นและรูปแบบเส้น ส่วนกรอบโปร่งเลือกได้ที่เส้นขอบ ไม่ใช่ตรงกลางว่าง
3. เลือกทึบ/ประ/จุดให้ปากกา เส้น ลูกศร และกรอบโปร่ง เปลี่ยนสีและขนาด 1/5/40 px
   คลิกช่องว่างของเส้นประเพื่อเลือกได้ หัวลูกศรยังทึบ ค่าเริ่มต้นแดง 5 px เส้นทึบ
4. ใช้เลือกคลิกเส้น/ลูกศร ลากจุดกลางเพื่อดัดโค้ง ปลายทั้งสองต้องไม่ขยับ
   หัวลูกศรต้องหมุนตามโค้ง ดับเบิลคลิกจุดกลางเพื่อคืนเส้นตรง
5. ลอง Undo/Redo หลังดัดและคืนตรง ต้องคืนในครั้งเดียว Esc ระหว่างดัดต้องยกเลิก
   โดยไม่เพิ่มประวัติ ย้าย/ลบ/จัดชั้นวัตถุที่โค้งแล้วและ Undo ต้องยังคืนได้
6. วางรูปทึบเหนือเส้นแล้วดัด เส้นเก่าต้องไม่ค้าง และวัตถุชั้นบนต้องไม่ถูกเส้นทับ
   ลองภาพยาว ตรวจการตอบสนองระหว่างลาก Copy/PNG ต้องตรงกันและไม่มีจุดจับติดไป
7. สลับ EN/TH ตรวจ Help/คำอธิบาย ย่อหน้าต่าง ลองจอ 125-200% และหลายจอต่างสเกล
8. ทดสอบไฮไลต์ ข้อความ ช่องคำพูด รวมหลายภาพ OCR และภาพยาว Lark/Esc Stop ซ้ำ

ขั้นตอนเดิมด้านล่างใช้กับ Alpha 10 ได้เช่นกัน
รายละเอียดผลตรวจและข้อจำกัดอยู่ใน docs/testing/0.9.0-alpha.10.md

## ภาพยาว: เก็บช่วงท้ายเมื่อหยุด

1. ปิดรุ่นเดิมจาก Tray แตก Alpha 10 ลงโฟลเดอร์ใหม่ เปิด EXE ตรวจ 0.9.0-alpha.10
2. เปิด Lark Sheet เดิม เลือก Automatic ตรวจกรอบและเริ่มจับภาพ
3. กด Esc ทันทีหลังเห็นตารางเลื่อน รอเก็บรอบสุดท้ายโดยหน้าจอต้องไม่เลื่อนเพิ่ม
   เทียบแถวล่างสุดที่เห็นจริงกับ PNG ต้องมีเนื้อหาถึงจุดเดียวกัน ไม่มีแถวซ้ำหรือขาด
4. ทดสอบปุ่ม Stop และ Esc ตอนพักด้วย กด Stop ซ้ำต้องไม่ยืดเวลารอ
5. ลอง Cancel ระหว่างขึ้นสถานะเก็บรอบสุดท้าย ต้องปิดทันทีและไม่มีพรีวิวเด้งตามหลัง
6. หากต้นทางถูกบัง/ย้าย หรือภาพไม่นิ่งภายในเวลา ต้องแจ้งว่าเก็บได้เพียงบางส่วน
   ไม่ฝืนต่อภาพ และไม่เลื่อนหน้าต่างอื่น ลอง Manual, Excel, EN/TH ซ้ำด้วย

## ไฮไลต์

1. บันทึกงานและปิด Rust Preview เดิมจาก Tray แตก ZIP Alpha 10 ไปโฟลเดอร์ใหม่
   เปิด SnapZy-Rust.exe ตรวจเวอร์ชัน 0.9.0-alpha.10
2. จับภาพข้อความสีดำ เลือกไฮไลต์ถัดจากปากกา ต้องเริ่มสีเหลือง ขนาด 24 px ความเข้ม 40%
   ลากขีดทับข้อความ ข้อความต้องยังอ่านได้ สี/ขอบขณะลากต้องตรงกับหลังปล่อย
3. ลองสีอื่น ขนาด 1-40 px และความเข้ม 0/40/100% ค่าต้องมีผลทันที
   Undo/Redo ต้องคืนสี ขนาด และความเข้ม แล้วลองวาดเส้นใหม่หลัง Undo
4. ใช้เลือกคลิกเส้นแล้วลากย้าย ลบ และ Undo ใช้ปุ่มจัดชั้นร่วมกับภาพ/ข้อความ/เบลอ
   Copy กับ Save PNG ต้องตรงกัน ไม่มีกรอบเลือกติดในไฟล์
5. สลับปากกา/ไฮไลต์ ปากกาต้องยังเริ่มสีแดง 5 px และจำค่าของแต่ละเครื่องมือแยกกัน
   ลากแล้วกด Esc ต้องไม่เพิ่มเส้น คลิกโดยไม่ลากต้องไม่สร้างเส้น
6. สลับ EN/TH ตรวจคำอธิบายและ Help ลองหน้าต่างเล็ก จอ 125-200% และหลายจอต่างสเกล
   ทดสอบจับภาพยาว Lark และ Esc Stop ซ้ำด้วย โดยต้องไม่หน่วงเพิ่ม

## รวมหลายภาพ

1. ปิด Rust Preview ที่เปิดอยู่ แตก ZIP alpha.10 ไปโฟลเดอร์ใหม่ แล้วเปิด EXE
   ตรวจเวอร์ชัน 0.9.0-alpha.10 จับภาพแล้วกด + เพื่อเพิ่ม PNG/JPEG/BMP ในงานเดิม
2. ใช้เลือกคลิกกลางภาพแล้วลากย้าย ลากแต่ละมุมเพื่อปรับขนาด ต้องรักษาสัดส่วน
   มุมตรงข้ามไม่ขยับ และภาพต้นฉบับยังคมชัดเมื่อขยายกลับ กด Escape ระหว่างลากเพื่อยกเลิก
3. คัดลอกภาพอีกใบแล้วใช้ปุ่มวางภาพหรือ Ctrl+V ในหน้าแก้ไข ต้องเป็นวัตถุอีกชั้น
   หากกำลังพิมพ์ข้อความ Ctrl+V ต้องวางข้อความในช่องพิมพ์ตามปกติ
4. กดปุ่มลูกศรสองทิศทางเพื่อขยายพื้นที่ กำหนดความกว้าง/สูง px พื้นที่ใหม่ด้านขวา/ล่าง
   ต้องเป็นสีขาว ภาพและวัตถุเดิมไม่ย้าย ใช้ Crop เพื่อลดขนาดพื้นที่
5. เพิ่มภาพที่ใหญ่กว่าพื้นที่เดิม ต้องขยายให้โดยไม่ย่อทับต้นฉบับ Undo ครั้งเดียว
   ต้องคืนทั้งภาพและขนาดพื้นที่เดิม ทดลอง Undo/Redo การย้าย ปรับขนาด ลบและจัดชั้นด้วย
6. วางภาพซ้อนลูกศร/ข้อความ ใช้ปุ่มจัดชั้นทั้ง 4 แล้ว Copy / Save PNG ภาพต้องตรงกัน
   ไม่มีจุดจับติดไป ตรวจขนาดพิกเซลด้วย ทดลองวางใน LINE และแอปแชทที่ใช้งานจริง
7. ทดลอง PNG โปร่งใส ไฟล์ชื่อไทย JPEG จากโทรศัพท์ และ BMP หากภาพใหญ่เกินกำหนด
   หรือไฟล์เสีย ต้องแจ้งเตือนและงานเดิมยังอยู่ ไม่ค้าง/ดับ ภาพที่ลบยังใช้หน่วยความจำ
   ถ้าเก็บใน Undo/Redo อยู่ ปิดหน้าแก้ไขเก่าเพื่อคืนหน่วยความจำ
8. สลับ EN/TH ตรวจคำอธิบายปุ่มและ Help ย่อหน้าต่าง และลองจอ 125-200%

## ตรวจของเดิม

1. บันทึกงานเก่าแล้วปิด Rust Preview ผ่าน Tray แตก ZIP alpha.10 ลงโฟลเดอร์ใหม่
   เปิด SnapZy-Rust.exe และตรวจเวอร์ชัน 0.9.0-alpha.10
2. จับภาพแล้ววาดวัตถุหลายชิ้นต่างสีให้ซ้อนกัน ใช้เครื่องมือเลือกคลิกวัตถุ
   ทดลองขึ้นบนสุด / ขึ้นหนึ่งชั้น / ลงหนึ่งชั้น / ลงล่างสุด ภาพต้นฉบับอยู่ล่างเสมอ
3. ตรวจปุ่มขึ้นเมื่อวัตถุอยู่บนสุดและปุ่มลงเมื่อล่างสุด ต้องกดไม่ได้
   หากไม่ได้เลือกวัตถุ ปุ่มทั้ง 4 ต้องกดไม่ได้
4. Undo/Redo ต้องคืนลำดับเดิมในครั้งเดียว ข้อความ พื้นหลังและหางช่องคำพูดไม่เปลี่ยน
   ลองเบลอซ้อนข้อความแล้วเปลี่ยนชั้น เบลอควรมีผลเฉพาะสิ่งที่อยู่ด้านล่าง
5. Copy และ Save PNG ต้องตรงกับลำดับใหม่ ไม่มีจุดจับติดในภาพ และความละเอียดเดิม
   สลับ EN/TH ตรวจคำอธิบายปุ่มและ Help รวมถึงหน้าต่างขนาดเล็กว่าปุ่มไม่ทับกัน
6. เลือก Automatic / อัตโนมัติ แล้วกด Scrolling / ภาพยาว วางเมาส์เหนือพื้นที่
   ตาราง รอกรอบสีโดยยังไม่คลิก ตรวจขอบเขตแล้วคลิกและปล่อยภายในกรอบหนึ่งครั้งเพื่อเริ่ม
   การตรวจจับต้องไม่เลื่อนตารางก่อนยืนยันและหน้าจอต้องไม่ซ่อน/เปิดกระพริบ
7. กด Pause / พัก รอแล้วภาพต้องไม่เลื่อนเพิ่ม กด Resume / ทำต่อ แล้วต้องทำต่อได้
8. สลับไปหน้าต่างอื่น หรือเปิดหน้าต่างบังตาราง โปรแกรมต้องพัก ไม่เลื่อนโปรแกรมอื่น
   กลับหน้าต่างต้นทาง ปิดสิ่งที่บัง แล้วกด Resume เอง โปรแกรมต้องไม่แย่งโฟกัสกลับ
9. กด Stop เพื่อเก็บภาพ หรือ Cancel เพื่อทิ้งงาน ตรวจว่าไม่เด้งภาพตามหลังการยกเลิก
   ทดลองกด Esc ระหว่างจับภาพขณะโฟกัสอยู่ที่ Lark ต้องหยุดและเปิดภาพส่วนที่สำเร็จ
   ทดลอง Esc ตอนพักด้วย ต้องเก็บภาพเหมือนกัน เมื่อจบงาน Esc ในแอปอื่นต้องทำงานตามปกติ
   หากไม่มีเนื้อหาใหม่หลังลองซ้ำ โปรแกรมจะเก็บภาพที่ยืนยันได้พร้อมแจ้งเหตุผล
   ข้อความนี้ไม่ได้รับประกันว่าเลื่อนถึงท้ายเอกสารแล้ว
10. ตรวจแถวต่อเนื่อง แถวตรึงแสดงครั้งเดียว แถบเลื่อนล่างไม่ซ้ำ Copy ไปวางแชท
   และ Save PNG ตรวจความคมชัดและขนาดพิกเซลเดิม
11. ทดลองทั้งสอง Lark Sheet ที่เคยมีปัญหา และ Excel โดยวางเมาส์ในตารางเพื่อ detect
   ตรวจขอบเขตและคลิกภายในเพื่อเริ่ม จากนั้นทดสอบทั้ง Automatic และ Manual / เลื่อนเอง
   ลองกด Escape ระหว่างขึ้นสถานะกำลังตรวจและหลังแสดงกรอบ ต้องยกเลิกได้ทันที
   หากไม่พบ pane ให้ย้ายเมาส์ไปตำแหน่งอื่น ต้องไม่มี fallback แบบลากเลือกกรอบ
   หากแสดงกรอบสีเหลือง/ข้อความกรอบหน้าต่าง ให้ตรวจขอบเขตก่อนคลิก ไม่ถือว่าเลื่อนได้แน่นอน
12. ตรวจข้อความ/ช่องคำพูด พื้นหลังเริ่มต้นโปร่งใส ปรับขนาดกรอบ ลากปลายหาง
   เปลี่ยนสีพื้นหลัง Undo/Redo และส่งออก ต้องยังทำงานเหมือนรุ่นก่อน
13. แจ้งความเร็วเปิดโปรแกรม/จับภาพ และการทดสอบจอ 125-200% หรือหลายจอสเกลต่างกัน

แนะนำวางเมาส์ในพื้นที่ตาราง ไม่เลือกทั้งจอจนไม่มีที่วางหน้าควบคุม หากพักเพราะรอยต่อ
ไม่ชัดเจน ให้ Stop เก็บภาพส่วนที่สำเร็จ แล้วลอง Manual
แอปที่รันด้วยสิทธิ์สูงกว่าอาจไม่รับคำสั่งเลื่อน รุ่นนี้ไม่ยกระดับสิทธิ์เอง

ยังไม่มีไฟล์โครงการ เงา หรือขอบตัวอักษรในรุ่นนี้ ควรส่งออก PNG ก่อนปิด
ระหว่างขึ้นสถานะกำลังตรวจจับ ลองกด Esc ต้องยกเลิกได้ ไม่มีผลตรวจเด้งตามหลัง
เมื่อระบบตอบช้าเกิน 4 วินาที อาจแสดงกรอบหน้าต่างสำรองที่มีป้ายกำกับ ไม่แอบเริ่มจับภาพเอง
ยังไม่ push หรือเผยแพร่จนกว่าผู้ทดสอบอนุมัติ ดู docs/testing/0.9.0-alpha.10.md
