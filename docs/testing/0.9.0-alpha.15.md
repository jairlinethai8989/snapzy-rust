# Alpha 15: Editable Image Combination

Date: 2026-10-12. Local Rust candidate only. No .NET changes, installer,
commit, push or public release. Alpha 14-r2 remains the accepted baseline.

## Scope

- Combine checked open editors into an independent unsaved project.
- Vertical/horizontal native-size layout, gap 0-500 px (default 16), or free
  placement with a 24 px stagger. Reorder sources before confirmation.
- Editable ownership up to eight image-group levels, sibling-only ordering,
  owner selection, group movement/uniform resize and per-image viewport crop.
- Source documents, selection, history and paths are not changed by combination.
- Shared source assets, bounded worker composition and prepared initial preview.
- Schema 2 saves ownership and viewports; schema 1 remains readable.
- Newly saved files require Alpha 15 or later. Use Save As to retain old files.
- Original pixels remain in projects beneath crop/blur. Share exported PNG
  instead of the project when hidden source data must not be included.
