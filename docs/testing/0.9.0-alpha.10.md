# SnapZy Rust Preview 0.9.0-alpha.10

Date: 2026-10-11 (Asia/Bangkok). Local test candidate only.
No commit, Git push, public release, installer or .NET changes.

## Scope

- Rectangle/ellipse outlines and filled rectangles/ellipses.
- Solid/dashed/dotted Pen, Line, Arrow and outline strokes. Filled shapes
  have no separate border. Highlighter defaults remain independent.
- Select a line/arrow and drag its visible midpoint to bend it. Endpoints
  stay fixed; the solid arrowhead follows the terminal tangent.
- Double-click the midpoint to straighten. Release commits one Undo step;
  Escape, tool changes and capture loss cancel an unfinished bend.
- Curve replacement feedback erases the old stroke and preserves upper
  objects, using bounded display patches and tiled source composition.
- Localized tooltips, pattern menu and English/Thai Help.

## Native Failure Found And Corrected

First native run failed at the ellipse corner pixel:
`artifacts/smoke-eeda303667fd40b2bf3f3d8e03892b95/partial-results.json`.
The exported ellipse was still a rectangle. The native command dispatcher
used a numeric range ending at the previous Opacity control and silently
ignored the new shape/pattern IDs. Replaced that upper-bound assumption
with the editor's declared button list plus its editable property controls.
A unit test now checks every declared command and excludes language/static
labels. This first run is a genuine failure, not a passing GUI result.
The routing test and corrected native rerun passed after the fix.

The next native attempt stopped at a fixture expectation error:
`artifacts/smoke-bae41206924c465c870b1c859207524c/partial-results.json`.
The actual blue preset is RGB(0,120,255), not System.Drawing.Color.Blue
(0,0,255). Corrected two expected pixels, without changing production colors.
The fixture now restores red explicitly before its arrow case: Undo restores
document history, not future-tool preferences.

The broad regression attempt stopped at a stale tooltip-count assertion:
`artifacts/smoke-b01093b81c1b43c290aef72f0f21f65c/partial-results.json`.
Highlighter, multi-image, layers, callout, paint, annotations and text-resize
sections completed with PASS before that failure; the overall run was FAIL.
The production tooltip list has 31 buttons plus five property/language
controls (36), while the fixture still expected the previous 32. Updated the
exact expected count to 36 and extended compact bounds checks to all four
new controls. Editor/OCR/scroll completion is not inferred from this attempt.
A subsequent bounded run passed those remaining sections separately. The
fixture now accepts an optional maximum duration and records an unverified
failure with cleanup if an agreed interval expires.

That broad attempt observed launcher/selection/preview windows at
392.69/247.06/58.01 ms. The previous slow launch sample is still retained;
these observations alone do not establish a startup speed improvement.

## Tester Steps

1. Exit the older Rust Preview via Tray, extract this candidate into a new
   folder and verify 0.9.0-alpha.10. Do not replace an installed .NET app.
2. Draw each outline/filled shape in both directions. Outline interiors
   should not select the shape; filled ellipse bounding-box corners should
   not select it. Filled shapes disable Width and Stroke Pattern.
3. Try solid/dashed/dotted strokes at 1, 5 and 40 px for Pen, Line, Arrow
   and outlines. Gaps remain selectable and arrowheads remain solid.
4. Select a line/arrow, drag its midpoint, Undo/Redo, double-click to reset,
   then Undo. Endpoints stay fixed. Escape midway must discard the bend.
5. Move, delete and reorder a curved object, then Undo. Put a filled shape
   above a curve and bend it: the old stroke must disappear and the upper
   object must stay above it. Repeat on a long image and watch response.
6. Copy and Save PNG: compare pixels, dimensions and absence of handles.
   Try EN/TH Help, small windows, 125-200% and mixed monitor scales.
7. Recheck Pen/Highlighter independent defaults, text/callouts, added images,
   layers, OCR and Lark automatic/manual scrolling with Escape/Stop tails.
