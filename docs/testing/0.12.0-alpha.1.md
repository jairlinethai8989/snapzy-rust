# SnapZy Rust 0.12.0-alpha.1 Test Notes

## Scope

This candidate extends one-way import of Neo Snap `.neosnap` version 1 projects
with editable numbered markers and blur regions. It preserves compatible source
position, size or blur strength, number, color, opacity, shadow, image ownership
and layer order. Imported objects remain editable and save only as a new
`.snapzy` project; the original `.neosnap` file is never overwritten.

Imported step markers use the .NET radius, white-ring and light/dark digit rules.
Their editor size is the .NET source size from 2 through 32 rather than the
native Rust circle diameter. Imported and newly created blur regions accept
1 through 64 px; the native default remains 8 px. Blur opacity now applies from
0 through 100 percent, including its compatible shadow.

Text and speech bubbles remain deferred. If any object or stored value cannot be
preserved, the complete import stops with an English or Thai explanation. No
object is dropped, flattened, reordered or clamped. Small differences at number
edges and in blur softness are expected because the two apps use different
raster and Gaussian implementations.

## Manual Test Checklist

1. Exit any older SnapZy Rust process, including its tray icon.
2. Extract `SnapZy-Rust-0.12.0-alpha.1-win-x64.zip` to a new folder and run
   `SnapZy-Rust.exe` from that folder.
3. In Neo Snap .NET, save a `.neosnap` file containing numbered markers and blur
   regions but no text or speech bubbles. Include single- and multi-digit markers,
   blur strengths 1, 30 and 64, opacity 0%, 50% and 100%, and a compatible shadow.
4. Open that `.neosnap` file in SnapZy Rust. Compare position, circle size, white
   ring, digit color, blur area/strength, opacity, shadow and layer order.
5. Select the imported markers. Change their source size from 2 through 32,
   color, opacity, shadow and layer order; verify Undo/Redo.
6. Select the imported blur regions. Change strength from 1 through 64, opacity,
   shadow, position and layer order; verify Undo/Redo. At 0%, the image beneath
   and the shadow must both be invisible while the object remains editable.
7. Repeat with a numbered marker and blur owned by an image that was resized in
   Neo Snap. Confirm their visible positions and sizes do not shift on import.
8. Use Copy Image and Save PNG. Confirm both outputs match the editor preview.
9. Save the imported work as `.snapzy`, close it, reopen it and confirm the
   objects and their rendering remain editable and unchanged.
10. Confirm the original `.neosnap` file is unchanged.
11. Try a `.neosnap` file containing text or a speech bubble. Confirm the whole
   import is rejected with an EN/TH explanation and no partial tab opens.
12. Open an older `.snapzy` schema 1 or 2 project and confirm it still works.

## Safety Notes

Blur is visual obfuscation, not secure redaction. Editable `.snapzy` projects
retain source pixels beneath blur. Share an exported PNG when the hidden source
data must not be included. This candidate is portable, does not install or update
the .NET application, and has not been committed, pushed or published.
