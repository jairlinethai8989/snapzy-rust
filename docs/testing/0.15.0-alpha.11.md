# SnapZy 0.15.0-alpha.11: Combine and Close All fixes

## Changes

- Side handles on editable combined images preserve the image group's aspect ratio so its child annotations keep a valid shared transform.
- Combined images can still move over one another; new annotations render above them normally.
- More → Close all tabs provides the save/discard/cancel workflow for every tab in the editor window.
- A preview rendering error no longer aborts the close workflow. Cancel keeps every tab open.

## Manual checks

1. Combine two images into one editable project.
2. Select a combined image, resize using each edge and corner, then move it over the other image.
3. Draw a pen stroke and a shape across the overlap; check Copy, PNG and project save/reopen.
4. Use Undo/Redo after resizing and moving.
5. Open More → Close all tabs. Choose Cancel: all tabs must remain.
6. Repeat and choose Save or Discard for each test tab: the editor window must close.

## Automated checks

- Rust regression reproduces the former invalid viewport after a side drag, then checks overlapping images, annotations, rendering and Undo.
- UI close regression includes a failed preview and verifies Cancel preserves tabs and Discard completes window closure.

## Notes

An already-invalid in-memory edit made with Alpha 10 can be undone there before saving, or recreated by combining the original tabs in Alpha 11. This fix prevents new invalid image-group resizes; it does not repair damaged project geometry automatically.
