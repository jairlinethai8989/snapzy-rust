# SnapZy 0.15.0-alpha.15 trial

This is a local installer trial. The public download still points to Alpha 14 until the user tests and approves this build.

Installer: `dist/SnapZy-Setup-0.15.0-alpha.15-win-x64.exe` (5,573,265 bytes)

SHA-256: `43F7BE1A8945A2690F043306C32A26FA043C3A5ACC78F2B3FF5828EBC0C047A9`

## Changes

- Drawing a pen stroke, line, shape, blur, or step returns to Select when the object is created. The new object remains active. Cancelling or making an invalid gesture leaves the drawing tool selected.
- Dragging from empty canvas selects fully enclosed objects. Group and Ungroup are available in the toolbar, the More menu at compact sizes, and with Ctrl+G / Ctrl+Shift+G. Dragging a member moves the group. Group metadata, Undo/Redo, duplicate, and delete are saved as editable `.snapzy` data in schema 6. Older project schemas remain readable.
- The + tab button creates a white 1024 × 768 canvas. More → Open image opens an existing image; More → Workspace resizes the blank canvas.
- Copy Image uses a clipboard icon. Duplicate Object uses a copy plus icon, with English and Thai tooltips.
