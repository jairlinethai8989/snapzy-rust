# Alpha 13: Object Shadows And Text Outlines

Local portable Rust candidate only. No commit, push or public release.
Keep accepted Alpha 12 separately. No .NET changes.

## Changes / สิ่งที่เพิ่ม

- Object shadows for all annotation types, inserted images and blur regions.
  Defaults OFF, black, softness 6 px, X/Y 3 px. Softness 0-32, offsets -32 to 32.
- Text and speech-bubble glyph outlines, OFF, black, 2 px; range 1-16 px.
- Compact Effects gear panel, color swatches and numeric steppers. Apply commits
  one object edit; Cancel/Esc/close discard the draft. Invalid numbers keep the
  panel open. Select edits only the selection; drawing modes also update defaults.
- Ordinary opacity applies once to the composed object/shadow group. Highlight
  ink retains multiply blending. Blur shadow never paints inside its rectangle.
- Source pixels/glyph masks stay unchanged; effects use bounded tiles and halos.
  Shadows filter only the required sampling region, keeping a separate path guard.
- Local EN/TH controls, tooltips and Help. Original-resolution Copy/PNG remains
  the same composition as preview. Earlier tools/defaults remain available.

## Tester Checklist

1. Enable a shadow on a rectangle. Try softness 0/6/32, positive/negative X/Y
   and different colors. Cancel and Esc must not change the object or defaults.
2. Try pen, highlighter, curved line/arrow, all shapes, number, text, bubble,
   transparent imported PNG and blur. Captured background has no effects.
3. Enable a text outline on Thai/English multiline text and a speech bubble.
   Check marks, glyph fill and wrapping; outline must not thicken bubble borders.
4. Apply once, Undo once, Redo once. No-op Apply must not add an Undo step.
5. Select an older object, change effects, then draw another object: Select edits
   must not replace defaults. Effects survive resizing, bending and text edits.
6. Try 0/50/100% object opacity, layers and crop. Blur still has no opacity setting.
7. Compare editor at 100%, Copy and PNG, including negative shadows near crop edges.
8. Recheck OCR and Lark long capture, Stop/Esc and the final captured rows.
