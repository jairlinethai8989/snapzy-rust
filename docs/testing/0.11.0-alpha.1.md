# SnapZy Rust 0.11.0-alpha.1 Test Notes

## Scope

This candidate adds one-way import of compatible Neo Snap `.neosnap` version 1
projects. Imported content remains editable and must be saved as a new `.snapzy`
project. SnapZy Rust never overwrites the source `.neosnap` file.

The importer preserves compatible PNG backgrounds and image layers, crops,
layer order, image-owned annotations, pen and highlighter paths, straight or
curved lines and arrows, outline or filled rectangles and ellipses, line styles,
opacity and compatible shadows. Imported pen smoothing, single-point dots and
arrowheads retain the .NET rendering rules after saving and reopening `.snapzy`.

The first candidate intentionally rejects the entire source file if any object
cannot be preserved. Text, speech bubbles, step numbers and blur are not yet
supported. No object is silently dropped, flattened, reordered or clamped.

## Manual Test Checklist

1. Exit any older SnapZy Rust process, including the tray icon.
2. Start `SnapZy-Rust.exe` from the 0.11.0-alpha.1 candidate folder.
3. In Neo Snap .NET, create and save a `.neosnap` project containing only the
   supported tools listed above.
4. In SnapZy Rust, use Open and select the `.neosnap` file.
5. Confirm the imported tab shows the source name and an unsaved state.
6. Compare background pixels, crops, layers, curves, pen smoothing, arrowheads,
   patterns, opacity and shadows with the .NET editor.
7. Move, resize, recolor, bend and reorder imported objects. Test Undo and Redo.
8. Test Copy Image and Save PNG.
9. Use Save As to create a `.snapzy` file. Close it, reopen it and confirm every
   imported object is still editable and visually unchanged.
10. Confirm the original `.neosnap` file is unchanged.
11. Try a file containing text, a speech bubble, step number or blur. Confirm
    the whole import is rejected with an English or Thai explanation and no
    partial tab is opened.
12. Open older `.snapzy` schema 1 and 2 projects and confirm they still work.
