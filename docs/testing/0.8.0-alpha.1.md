Date: 2026-10-10, Asia/Bangkok. Local portable tester candidate only.
No commit, push, tag, installer or public release. Neither .NET app was changed.

## Candidate

- Executable: 1,505,792 bytes, ProductVersion/FileVersion 0.8.0-alpha.1.
- SHA256: `1CFBEC248340EE9E8586C164A37A7CAEEF05989AABE380D1DB5781B33A4242B5`.

## Limits And Tester Checks

Encoded inputs, expanded canvas buffers and aggregate retained image sources
have separate 32 MiB limits. Source accounting includes captured frames and
unique imported images in Undo/Redo across open editors. Deleted images can
therefore still consume the allowance. These are not a total process RAM cap;
decoder buffers, composition, glyphs, UI and history use additional memory.
Decoding runs on a background worker with format/dimension/budget checks and
stale-editor identity guards. Only one import runs at a time.

- Run the packaged candidate; add files and clipboard images, move/resize/order,
  crop/expand, Undo/Redo and inspect saved pixel dimensions.
- Try transparent PNG, Unicode filenames, oriented phone JPEG and real clipboard
  producers. Test Copy in LINE and other actual chat applications.
- Test both supplied Lark sheets and Excel, Automatic and Manual.
- Check high/mixed DPI 125-200%, physical hotkeys, tray restore, large projects
  and startup latency on target PCs. These were not verified by this increment.

See TESTER-CHECKLIST.md. Export PNG before closing: editable projects are absent.
Blur is visual obfuscation, not secure redaction. No public push before approval.
