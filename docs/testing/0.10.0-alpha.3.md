## Native Checklist

1. Record a short silent clip. Stop/Esc must open a paused preview, not Save.
2. Play/pause, seek forwards/backwards and replay at the end. Verify actual
   visible pixels and duration. Record system/microphone/both clips and check
   audible playback/sync, mute and volume; no unexpected autoplay sound.
3. Resize to minimum and maximize; EN/TH labels/tooltips must fit. Keyboard Tab
   visits controls. Esc requests the preview's close flow, not recording Stop.
4. Cancel Save: preview stays open. Save to a new Unicode path: original stays
   and saved bytes match. Existing destinations and missing folders report an
   error without replacing/deleting files. Large exports stay responsive.
5. Copy Clip, paste into a supported chat manually, then Save/close preview and
   paste again. Check recipient yourself; automated tests must never send.
6. Close without Copy/Save: Save / Keep Local / Cancel. Cancel keeps the clip;
   Keep Local closes but preserves it. Exit with multiple unkept clips, choose
   Keep Local then Cancel: every preview must still be open.
7. Start another recording while a preview plays: preview pauses/hides, restores
   paused afterwards, and is absent from recording. Eight previews are the limit;
   further completed clips are retained with their location shown.
8. Check media load errors, close during loading and Exit during export. Clips
   survive unavailable playback. Never delete completed/partial or user-owned
   files during these checks.

Run `tools/test-video-preview.ps1` only in an agreed native test window. It creates
its own fixture, records that window with no audio and confines actions to its
test process. Interactive clipboard automation is now disabled: `-AllowClipboard`
fails before creating any UI or accessing the clipboard. An isolated native
clipboard test is explicitly ignored by default and requires a host that permits
private window stations; this host returned Access Denied before any clipboard
access. Do not bypass this restriction by using the interactive clipboard.

Native testing found a test-harness failure restoring an OLE clipboard proxy,
not an application crash. Restoration of the user's earlier clipboard could not
be confirmed. The unsafe restore path was removed. The subsequent no-clipboard
runs confirmed recording -> paused visible preview, actual fixture pixels,
playback controls and Save Cancel. After fixing cross-process filename-control
inspection, the remaining native run passed actual Save, source retention,
exact exported bytes, EN/TH title refresh, minimum control bounds, Keep Local
then Cancel across two previews, and clean exit. This run did not access the
clipboard. An obscured preview screenshot was rejected as a setup issue; the
helper now checks preview ownership before sampling screen pixels.
See 2026-10-15-alpha3-native-check.md for evidence and remaining checks.
