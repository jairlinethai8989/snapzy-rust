# SnapZy 0.15.0-alpha.14

Versioned source release of the workspace navigation and installer correction tested by the user in Alpha 13.

- Hand toggle, Space + drag, middle-button drag, wheel/Shift-wheel navigation, reachable pan bounds, and Fit recovery.
- Installer process guard includes the background engine. The migration script is tracked in `src-tauri/windows` beside its NSIS hook so clean checkouts contain the installer source.
- User guides and README describe the new behavior. The README download remains the latest published release until a new installer is published.

Verification from `experiments/tauri`:

```text
npm test
npm run build
node tests/editor-pan-ui-smoke.mjs
node tests/close-all-ui-smoke.mjs
node tests/installer-process-smoke.mjs
```

The browser smoke tests use `npm run dev`. The installer test uses the prepared engine under `src-tauri/resources/engine`, starts its own real child engine and filters process enumeration to that fixture so running user sessions remain untouched.
