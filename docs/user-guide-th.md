# คู่มือผู้ใช้ SnapZy 0.15.0-alpha.10

คู่มือนี้อ้างอิงหน้าตา SnapZy Rust `0.15.0-alpha.10` และอธิบายปุ่มบนหน้าจอจับภาพกับหน้าแก้ไขภาพ ภาพประกอบใช้ข้อมูลตัวอย่างที่สร้างขึ้นสำหรับคู่มือ

## ภาพรวมหน้าจอ

### หน้าจับภาพ

| หมายเลข | ปุ่ม/ส่วนควบคุม | วิธีใช้ |
| --- | --- | --- |
| 1 | **พื้นที่** | ลากเลือกบริเวณที่ต้องการจับภาพ |
| 2 | **หน้าต่าง** | เลือกหน้าต่างเป้าหมาย ปุ่มลูกศรข้างกันใช้เลือกจับภาพเดสก์ท็อปทั้งหมด |
| 3 | **ภาพยาว** | จับภาพบริเวณที่เลื่อนได้ โหมดอัตโนมัติหรือเลื่อนเองเลือกได้ที่หมายเลข 6 |
| 4 | **วิดีโอ** | เปิดหน้าต่างตั้งค่าแหล่งภาพและเสียงก่อนเริ่มอัด เลือกหน้าจอหรือหน้าต่าง และเลือกเสียงได้ |
| 5 | **หน่วงเวลา** | ตั้ง 0, 3, 5 หรือ 10 วินาที ใช้กับการจับภาพครั้งถัดไป |

| 7 | **เปิดผลลัพธ์ใน** | เลือกเปิดภาพที่จับในแท็บใหม่หรือหน้าต่างใหม่ |
| 8 | **ปุ่มด้านบน** | เปิดหน้าแก้ไขภาพ, สลับภาษาไทย/อังกฤษ และเปิดเมนูเพิ่มเติม |

เมนูเพิ่มเติมมีคำสั่งจับทั้งเดสก์ท็อป ตั้งค่าคีย์ลัด และเกี่ยวกับ SnapZy

### หน้าแก้ไขภาพ

![หน้าแก้ไขภาพ SnapZy พร้อมหมายเลขกำกับ](images/snapzy-editor-overview.png)

| หมายเลข | ปุ่ม/ส่วนควบคุม | วิธีใช้ |
| --- | --- | --- |
| 1 | **แท็บงาน** | สลับระหว่างภาพที่เปิดอยู่ ปุ่ม `+` เปิดภาพเพิ่ม |
| 2 | **คำสั่งด้านบน** | เมนูเพิ่มเติม, พื้นที่ทำงาน, รวมภาพ, OCR, วิธีใช้, สลับภาษา, คัดลอกภาพ และบันทึกเป็น PNG |
| 3 | **เลือก / ครอบตัด / สำเนาพื้นที่** | เลือกและแก้ไขวัตถุ, ครอบภาพ หรือวาดกรอบเพื่อสร้างสำเนาพื้นที่เป็นวัตถุใหม่ |
| 4 | **ปากกา / ไฮไลต์ / เส้น / ลูกศร** | เลือกเครื่องมือแล้วลากบนภาพเพื่อวาด |
| 5 | **รูปทรงโปร่ง / ทึบ** | เปิดเมนูเพื่อเลือกรูปสี่เหลี่ยมหรือวงรี จากนั้นลากเพื่อวาด |
| 6 | **เบลอ / เลขลำดับ / ข้อความ / ช่องคำพูด** | วาดพื้นที่เบลอหรือวางองค์ประกอบบนภาพ ข้อความและช่องคำพูดเปิดหน้าต่างให้พิมพ์ก่อนวาง |
| 7 | **เอฟเฟกต์ / ลำดับชั้น** | ตั้งเงาหรือขอบอักษร และจัดว่าวัตถุอยู่ด้านหน้าหรือด้านหลัง |
| 8 | **จัดการวัตถุและประวัติ** | สำเนาวัตถุที่เลือก, ลบ, ย้อนกลับ และทำซ้ำ |
| 9 | **แถบปรับเครื่องมือ** | เลือกสี ขนาด รูปแบบเส้น ฟอนต์ พื้นหลังข้อความ และความโปร่งใส ตามเครื่องมือที่เลือก |
| 10 | **ซูมและพอดี** | ซูมเข้า/ออก เลือกระดับซูม หรือกด **พอดี** เพื่อแสดงภาพทั้งหมด |
| 11 | **พื้นที่ทำงาน** | วาดและแก้ไขภาพ พื้นตารางหมากรุกแสดงพื้นที่โปร่งใส |

## เริ่มแก้ไขภาพ

1. จับภาพจากหน้าหลัก หรือเปิดไฟล์ PNG, JPEG หรือ BMP ด้วยปุ่ม `+` หรือปุ่มเปิดภาพในหน้าแก้ไข
2. เลือกเครื่องมือจากแถบด้านบน แล้วลากบนพื้นที่ทำงานเพื่อสร้างวัตถุ หากเป็นข้อความหรือช่องคำพูด ให้พิมพ์ข้อความในหน้าต่างที่เปิดขึ้น
3. เมื่อเลือกวัตถุแล้ว ลากเพื่อย้ายหรือปรับขนาด ใช้แถบปรับเครื่องมือเพื่อเปลี่ยนสี ขนาด รูปแบบเส้น ฟอนต์ พื้นหลัง หรือความโปร่งใส
4. ใช้ **คัดลอกภาพ** เพื่อคัดลอกภาพที่แก้แล้ว หรือ **บันทึก PNG** เพื่อส่งออกเป็นไฟล์ภาพ

## รวมภาพจากหลายแท็บ

1. เปิดภาพอย่างน้อยสองแท็บในหน้าต่างแก้ไขเดียวกัน
2. กด **รวมภาพ** (ไอคอนภาพซ้อนกัน) ข้างเมนูเพิ่มเติม หรือเลือก **รวมภาพ** ในเมนูเพิ่มเติม
3. เลือกแท็บที่จะรวม ใช้ลูกศรเปลี่ยนลำดับ เลือกแนวตั้ง แนวนอน หรือวางอิสระ และกำหนดระยะห่าง 0–500 px เมื่อจัดวางอัตโนมัติ
4. กด **รวมภาพ** โปรแกรมจะเปิดงานใหม่ในแท็บใหม่ ภาพต้นทางไม่เปลี่ยน และภาพกับวัตถุเดิมในงานรวมยังแก้ไขต่อได้ บันทึกเป็นไฟล์ `.snapzy` เพื่อเปิดมาแก้ภายหลัง

## ซูมและคีย์ลัด

- `Ctrl` + ล้อเมาส์: ซูมเข้า/ออกโดยยึดตำแหน่งเมาส์
- `Space` + ลาก: เลื่อนพื้นที่ทำงาน
- `Ctrl` + `+` หรือ `=`: ซูมเข้า; `Ctrl` + `-`: ซูมออก; `Ctrl` + `0`: แสดงภาพให้พอดี
- `Ctrl` + `Z`: ย้อนกลับ; `Ctrl` + `Shift` + `Z` หรือ `Ctrl` + `Y`: ทำซ้ำ
- `Ctrl` + `D`: สำเนาวัตถุที่เลือก; `Delete`: ลบวัตถุ
- `Enter`: ยืนยันการครอบตัด; `Esc`: ยกเลิกเมนูหรือการทำงานที่กำลังค้างอยู่

## ปรับขนาดพื้นที่ทำงาน

1. เปิด **เมนูเพิ่มเติม** แล้วเลือก **พื้นที่ทำงาน**
2. กำหนดความกว้างและความสูงใหม่เป็นพิกเซล พื้นที่จะขยายไปทางขวาและด้านล่าง หรือจะตัดเนื้อหานอกขอบใหม่เมื่อปรับให้เล็กลง
3. กด **ใช้ขนาดนี้** การเปลี่ยนแปลงจะเป็นหนึ่งขั้นของ Undo/Redo และอยู่ในสถานะงานที่ต้องบันทึก
4. หากลดขนาดด้านใดด้านหนึ่ง ระบบจะแจ้งเตือนให้ยืนยันก่อนใช้ และกด **Undo** เพื่อคืนพื้นที่เดิมได้

## ข้อจำกัดของ Alpha 10

เมนู **OCR** และ **เพิ่มภาพ** ยังแสดงอยู่แต่ยังไม่เชื่อมต่อใน Tauri Editor ส่วน **เปิดไฟล์งาน**, **บันทึก** และ **บันทึกเป็น** ใช้ไฟล์งาน `.snapzy` ที่แก้ไขต่อได้แล้ว การคัดลอกภาพและบันทึก PNG ยังคงเป็นการส่งออกภาพ และไม่ถือว่าเป็นการบันทึกไฟล์งาน
